# DSA Problems - Organized by Category

This repository contains Data Structures and Algorithms (DSA) problems organized into logical categories for easy navigation and learning.

## Directory Structure

### 1. **String Manipulation** (`1_string_manipulation/`)
Problems related to string operations, pattern matching, and text manipulation.
- `anagram.cpp` - Check if two strings are anagrams
- `pallindrome.cpp` - Check if a string is a palindrome
- `longest_pallindrome.cpp` - Find the longest palindromic substring
- `make_pallindrome.cpp` - Create a palindrome from a string
- `first_non_repeating.cpp` - Find first non-repeating character
- `ext_sum_alphanum.cpp` - Extract sum of alphanumeric characters
- `rev_sen.cpp` - Reverse sentence operations
- `hello_without_sc.cpp` - String manipulation without special chars

### 2. **Number Theory** (`2_number_theory/`)
Problems dealing with numbers, number properties, and mathematical sequences.
- `armstrong_number.cpp` - Check Armstrong numbers
- `prime.cpp` - Prime number checking
- `perfect_num.cpp` - Perfect number checking
- `odd_even.cpp` - Odd/even number classification
- `fibonacci.cpp` - Fibonacci sequence generation

### 3. **Number Conversion** (`3_number_conversion/`)
Problems involving conversion between different number systems.
- `bin_to_dec.cpp` - Binary to decimal conversion

### 4. **Array & Subarray** (`4_array_subarray/`)
Problems involving array manipulation, subarray problems, and range queries.
- `max_subarray.cpp` - Find maximum sum subarray (Kadane's algorithm)
- `min_size_sub_array_sum.cpp` - Find minimum size subarray with given sum
- `max_fixed_subarray_sum.cpp` - Maximum sum in fixed-size subarray
- `longest_subarray.cpp` - Find longest subarray based on conditions
- `count_leaders.cpp` - Count array elements greater than all right elements
- `largest_rectangle_in_histogram.cpp` - Largest rectangle in histogram
- `eq_index.cpp` - Equilibrium index in array

### 5. **Sorting** (`5_sorting/`)
Sorting algorithms and related problems.
- `bubble_sort.cpp` - Bubble sort implementation
- `category_sorting.cpp` - Sorting with category-based logic

### 6. **Matrix** (`6_matrix/`)
Matrix operations and transformations.
- `transpose.cpp` - Matrix transpose operation

### 7. **Geometry** (`7_geometry/`)
Geometric computations and problems.
- `area_triangle.cpp` - Calculate triangle area

### 8. **Miscellaneous** (`8_miscellaneous/`)
Additional files, test files, and debug symbols.
- `check.cpp` - Utility check function
- `container.cpp` - Container/data structure utilities
- `conveyor_belt.cpp` - Conveyor belt problem
- `swap.cpp` - Swap operation implementations
- `test.cpp` - Test file
- `main` - Compiled executable
- `*.dSYM/` - Debug symbol files

## How to Use

1. Navigate to the category folder you want to study
2. Open the relevant `.cpp` file to review the implementation
3. Study the algorithm and approach
4. Compile and run: `g++ <filename>.cpp -o <executable_name>`
